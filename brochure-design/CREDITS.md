# Credits

> Modified by Okou: the original upstream credits are preserved below for attribution.
> They describe the broader Folio project, not this curated package's feature/file
> inventory. See UPSTREAM.md for included components, exclusions and separately
> retained notices. No private boards, maintainer preferences or automatic learning
> behavior are imported.

Folio adapts ideas — and in one case an approach to code — from these open-source projects. All are MIT or Apache-2.0 licensed; thank you to their authors.

| Project | License | What folio took |
|---|---|---|
| [pbakaus/impeccable](https://github.com/pbakaus/impeccable) | Apache-2.0 | anti-slop philosophy, reflex-reject fonts, colour strategies, register idea, command/reference structure; v0.4: font-selection procedure, second-order lane reflex, light-on-dark type compensation, paragraph spacing rule, colour-blind-safe charts, eye-before-detector critique |
| [alchaincyf/huashu-design](https://github.com/alchaincyf/huashu-design) | MIT | measuring the *rendered* DOM to produce editable output (`pptx_from_rendered.py`) — the basis of `editable.py`'s approach (whitespace collapsing, line clustering, container-width text boxes); facts-first principle |
| [Nutlope/hallmark](https://github.com/Nutlope/hallmark) | MIT | pre-flight scan before asking; always-ask-once context gate with "go ahead"; six-axis pre-emit self-critique and output stamp; structural variety across outputs; treating design files as data |
| [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | MIT | one-line Design Read; three dials inferred from the brief; banned generic copy words; combinatorial image-prompt engine; v0.4: palette-family rotation, italic descender clearance, redesign protocol, narrative spine, spec clusters, copy micro-rules |
| [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | MIT | searchable local design data (industry → palette) with contrast-corrected colours |
| [jiji262/claude-design-skill](https://github.com/jiji262/claude-design-skill) | MIT | design-direction advisor drawing from different schools; item-by-item brand-asset protocol; verify facts before assuming |
| [hussainnasser1996-stack/print-studio](https://github.com/hussainnasser1996-stack/print-studio) | MIT | lock direction before layout; read back every rendered page; hidden-overflow measurement; page-fill discipline; content-completeness check; self-improving skill loop with changelog |
| [latent-spaces/brag](https://github.com/latent-spaces/brag) | MIT | turning finished work into launch assets: storyboarded short reel, poster frame, share copy, checking stills, "show the real thing" |
| [bluedusk/html-magazine](https://github.com/bluedusk/html-magazine) | MIT | copy rewrite levels |
| [anthropics/claude-plugins-official · frontend-design](https://github.com/anthropics/claude-plugins-official) | Apache-2.0 | the five clusters where generated design lands, template-chrome tells, "visual structure is information", the similar-brief test, serif measure and leading |
| [blader/humanizer](https://github.com/blader/humanizer) | MIT | the AI-writing pattern catalogue, vendored unchanged as `reference/humanizer.md` (with its licence notice) and adapted for print in `reference/copy.md`; the measurable tells in `preflight.py` |
| [nexu-io/html-anything](https://github.com/nexu-io/html-anything) | Apache-2.0 | a working example per template |

Reference boards in `skills/folio/library/references/` are other designers' work, kept as private study material; they are excluded from public repos by `.gitignore`.
