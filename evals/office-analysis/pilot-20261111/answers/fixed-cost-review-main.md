# 第三季度经营例会短报告

收入下降是利润缺口主因，建议优先推进待验收事项，再核清费用和成本偏差。

本季收入较预算下降25%，营业利润下降83.3%，毛利率由60%降至50%。

| 项目（万元，人民币不含税） | 预算 | 实际 | 实际－预算 |
|---|---:|---:|---:|
| 收入 | 24.0 | 18.0 | −6.0 |
| 销售成本 | 9.6 | 9.0 | −0.6 |
| 毛利 | 14.4 | 9.0 | −5.4 |
| 营业费用 | 7.2 | 7.8 | +0.6 |
| 营业利润 | 7.2 | 1.2 | −6.0 |

**事实与测算。**销售成本下降不代表节约：固定收费仍为6万元，按实际收入及预算15%变动费率，成本基准为8.7万元，实际高出0.3万元。按预算成本模型分解，利润缺口为收入减少影响5.1万元、成本超基准0.3万元及营业费用超支0.6万元，合计6万元。固定成本占收入比上升，是毛利率下降的重要因素。

销售报告称，收入缺口包括待验收递延4万元、取消2万元；验收尚未发生。下季服务预收3万元已正确排除于本季收入。

**建议优先事项。**

1. 销售与交付先核实4万元待验收事项的未结条件、责任人与预计验收时间，并复盘2万元取消原因。收入影响占利润缺口85%，应优先处理；验收及收入恢复仍有不确定性，不承诺补回利润。
2. 财务逐项对账营业费用，查明0.6万元超支的用途与可控性，再提出控制措施；目前费用类别尚未核清。
3. 财务与交付核对0.3万元成本偏差，补齐加急外包金额及依据。现有资料不能认定全部偏差由外包造成，也不足以区分数量、产品组合或供应商费率影响。
