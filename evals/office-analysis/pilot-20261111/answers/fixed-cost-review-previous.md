# 第三季度经营复盘

本季营业利润1.2万元，较预算少6万元（下降83.3%）。按预算成本规则分解，收入缺口贡献利润差额的85%。建议优先排查验收障碍、重估收入兑现时间，同时核查成本与费用异常。

| 指标 | 预算 | 实际 | 实际减预算 |
|---|---:|---:|---:|
| 收入（万元） | 24.0 | 18.0 | −6.0 |
| 销售成本（万元） | 9.6 | 9.0 | −0.6 |
| 毛利（万元） | 14.4 | 9.0 | −5.4 |
| 经营费用（万元） | 7.2 | 7.8 | +0.6 |
| 营业利润（万元） | 7.2 | 1.2 | −6.0 |
| 毛利率 | 60% | 50% | −10个百分点 |

差异依据：收入少6万元，其中4万元待验收递延、2万元取消。销售成本中的固定承诺6万元实际未变，不能随收入同比下调；按实际收入重算，预算成本应为6＋18×15%＝8.7万元，实际高出0.3万元。营业利润桥为7.2−6×85%−0.3−0.6＝1.2万元。因此，成本较原预算少0.6万元不代表效率改善；毛利率下滑包含固定成本占收入比重上升的影响。上述为预算规则下的算术分解，并非因果证明。

建议管理层先由销售与交付列明4万元待验收事项的完成条件、责任人与预计时点，更新递延及取消后的收入预测；尚未验收，不能承诺收入或利润补回。再由财务核对加急外包金额及入账，并拆分核实经营费用超支0.6万元，据核查结果决定控费措施。外包金额未提供，且缺少数量、产品组合及供应商费率记录，不能将成本超支全部归于外包。下季服务预收款3万元已正确排除本季收入，应保持该口径。

数据来源：results.csv、notes.md；金额均为人民币、不含税。
