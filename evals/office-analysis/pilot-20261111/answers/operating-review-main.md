# Q3经营例会短报告

本季度经营利润为1.2万元，仅达预算的16.7%。管理层应优先推进待验收项目，并核清销售成本偏差；两者分别关系到收入兑现与盈利能力。

金额单位：万元人民币，不含税；差额＝实际－预算。

| 指标 | 预算 | 实际 | 差额 |
|---|---:|---:|---:|
| 收入 | 24.0 | 18.0 | −6.0 |
| 销售成本 | 9.6 | 9.0 | −0.6 |
| 毛利 | 14.4 | 9.0 | −5.4 |
| 毛利率 | 60% | 50% | −10个百分点 |
| 运营费用 | 7.2 | 7.8 | +0.6 |
| 经营利润 | 7.2 | 1.2 | −6.0 |

**事实与测算。**收入低于预算25%。销售报告称，4万元因待验收而延期、2万元被取消，合计对应6万元收入缺口；验收尚未完成。下季度服务的3万元收款已正确排除在本季收入外。

销售成本虽比原预算少0.6万元，但按预算成本率40%及实际收入计算，成本基准为7.2万元，实际高出1.8万元。经营利润缺口6万元可按预算模型分解为：收入基数减少影响3.6万元、销售成本高于上述基准影响1.8万元、运营费用超支影响0.6万元。该分解不等于原因认定：缺少数量、产品结构和供应商费率，无法区分相关影响；加急外包金额未提供，不能据此解释全部成本偏差。

**建议。**第一，由销售与交付逐项核实4万元待验收项目的障碍、责任人和预计验收时间，按验收进展更新收入预测；复盘2万元取消原因，评估后续订单风险。第二，由财务与交付核对项目成本和外包凭证，量化1.8万元偏差的来源，再决定采购或交付调整。第三，财务先对账运营费用分类，定位0.6万元超支，再提出有依据的支出措施。现有资料不足以承诺收入回补或降本金额。
