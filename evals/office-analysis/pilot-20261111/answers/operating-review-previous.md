# 第三季度经营例会短报告

本季营业利润为1.2万元，比预算少6万元，下降83.3%。收入下降25%，毛利率由60%降至50%，收入不足与成本率上升共同挤压利润。

金额单位：万元人民币，不含税；差额＝实际－预算。

| 指标 | 预算 | 实际 | 差额 |
|---|---:|---:|---:|
| 收入 | 24.0 | 18.0 | −6.0 |
| 销售成本 | 9.6 | 9.0 | −0.6 |
| 毛利 | 14.4 | 9.0 | −5.4 |
| 经营费用 | 7.2 | 7.8 | +0.6 |
| 营业利润 | 7.2 | 1.2 | −6.0 |

按预算模型的40%销售成本率，实际收入对应成本应为7.2万元，实际高出1.8万元。因此，6万元利润缺口可分解为：收入不足影响3.6万元、销售成本率偏离影响1.8万元、经营费用超支影响0.6万元。这是算术分解，并非因果证明；成本总额下降不能证明效率改善。

收入缺口中，4万元待验收递延，2万元取消。验收尚未完成，递延收入不能视为确定回补；下季服务预收款3万元已正确排除，不应填补本季收入缺口。

建议管理层优先并行处理两项：一是由销售、交付核清4万元的验收障碍、责任人与进度，确认能否及何时满足收入确认条件；二是由财务、交付核对加急外包金额与成本明细，解释1.8万元偏差。前者涉及最大待解决收入，后者涉及已发生的成本率偏离。随后核对经营费用类别，定位0.6万元超支及可控项目，并复盘取消订单。缺少数量、产品组合及供应商费率，暂不能判断单位成本或量价影响；外包金额未知，不能认定其造成全部偏差，也不能承诺追回利润。
