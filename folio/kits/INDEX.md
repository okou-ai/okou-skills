These are actual HTML/CSS layouts, not prompts or flattened author-preview images.
Photo/portrait/mark slots and fictional sample copy must be replaced. kit.py new
assembles each layout with the local font/page-system dependencies; raw kit.html
files are source templates, not standalone assembled projects.

The other eight upstream kits are excluded pending reference-design redistribution
rights evidence. This is not a library of finished flyers or preimposed trifold
brochures. Use the page system and generic pattern cards for original single sheets.
