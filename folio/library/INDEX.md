# Folio composition pattern library

> **Modified by Okou.** Curated and rewritten as portable composition guidance, not executable templates.

These 23 cards are optional design tools, **not user preferences, house rules or remembered taste**. Choose from the current brief, approved copy, available assets and output constraints. Dimensions are starting points for A4 unless stated otherwise; adapt and inspect at final size. Cards do not promise editable imports or identical rendering across applications.

## Read only 1–3 cards for the current decision

- **Opening a section:** choose one structure—[full-bleed opener](patterns/full-bleed-opener.md), [band stack](patterns/band-stack.md) or [split panel](patterns/split-panel.md). Add one type device only if needed.
- **Making a cover:** choose [cut-out masthead](patterns/cutout-masthead.md) or [cut-out layers](patterns/cutout-layers.md), not both recipes. Read [two-tone headline](patterns/two-tone-headline.md) only if the wording supports it.
- **Presenting evidence:** choose [stat spread](patterns/stat-spread.md), [data on tint](patterns/data-tint.md) or [map reach](patterns/map-reach.md) according to the data; add [numbered sequence](patterns/numbered-sequence.md) only for actual order.
- **Building a quiet narrative page:** start with [quote + portrait](patterns/quote-portrait.md), then optionally [offset block](patterns/offset-block.md) or [sketch spot](patterns/sketch-spot.md).
- **Linking a spread:** choose [gutter box](patterns/gutter-box.md) or [flow divide](patterns/flow-divide.md); confirm binding constraints before crossing the fold.

Do not load the whole library or stack devices to fill space. One structural pattern plus one supporting device is usually enough; a third card should solve a specific remaining problem.
