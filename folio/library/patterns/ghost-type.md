# Ghost type

> **Modified by Okou.** Adapted from Folio; [source and authorship](../INDEX.md#source-and-authorship).

**Use for:** Adding scale to an otherwise quiet opener without introducing another image or new information.

**Composition**
- Set one existing section word, year or number much larger than the live heading, behind or beside it.
- Start around 120–240pt on A4, using an outline or a very pale fill. A 5–8% ink tint is a starting experiment, not a print guarantee.
- Crop the decorative word at an outer edge if that strengthens scale; keep the actual heading fully readable.

**Control the hierarchy**
- Keep the decorative form away from dense body copy, where even faint edges can disrupt reading.
- Reserve it for selected transitions rather than every page. Compare neighbouring spreads to preserve contrast in pacing.
- The ghost word should repeat information already present in live text; never make faint lettering the only label.

**Watch for:** Competing headline scales, ghost strokes visible through paragraph counters, or a tint that vanishes or becomes too dark in print.

**Construction:** Layer decorative text separately and hide duplicates from assistive technology where appropriate. Check outline-stroke rendering and clipping in the actual PDF or image output.
