# Numbered index

> **Modified by Okou.** Adapted from Folio; [source and authorship](../INDEX.md#source-and-authorship).

**Use for:** A short table of contents where section entry pages can become the main graphic structure.

**Composition**
- Arrange five to nine section blocks in a regular grid; group subtopics rather than giving every item equal prominence.
- Use large page numerals, short section titles and an optional one-line description.
- A dark or saturated ground can make the contents a visual pause; a light ground is equally valid when contrast and hierarchy are strong.

**Starting points**
- On A4, try 40–70pt numerals, 10–12pt section titles and readable 9–10pt descriptions.
- Align numeral baselines and text starts. Allow space for the widest number and longest title.
- Make clear that the numbers are page references, not section sequence numbers. Use a heading or label if ambiguity remains.
- A rotated side title can frame the grid, but keep an ordinary reading-order heading available in digital output.

**Watch for:** Attractive but incorrect page references, descriptions competing with titles, or too many entries for display-scale numerals.

**Construction:** Set each entry as a number/title/description group. Recheck every reference against the final paginated output after content changes; link entries in digital versions when supported.
