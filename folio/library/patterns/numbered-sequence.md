# Numbered sequence

> **Modified by Okou.** Adapted from Folio; [source and authorship](../INDEX.md#source-and-authorship).

**Use for:** Steps, ranked items or milestones where order actually carries meaning.

**Composition**
- Pair each large numeral with a short title and one or two lines of explanation.
- Align numerals on a common left edge for a vertical sequence, or a shared baseline for a horizontal one.
- A thin connecting rule can reinforce continuity; leave a deliberate break around labels and circles.

**Starting points**
- Try three to six items with 24–40pt numerals on A4. Longer processes usually need smaller text, grouped phases or another page.
- Use one accent for numbers and a quieter body style for descriptions.
- For a timeline, equal spacing means ordinal milestones unless proportional time spacing is explicitly used. State the dates and avoid implying a false time scale.
- For unordered themes, use headings or bullets instead of imposing a sequence.

**Watch for:** Numbering added solely as decoration, connectors crossing text, or unequal explanation lengths breaking the rhythm.

**Construction:** Use an ordered list for steps and separate visual styling for numerals. Preserve reading order when arranging the list horizontally.
