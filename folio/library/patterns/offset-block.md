# Offset block

> **Modified by Okou.** Adapted from Folio; [source and authorship](../INDEX.md#source-and-authorship).

**Use for:** Giving a rectangular image depth through a shifted solid colour plane rather than a realistic shadow.

**Composition**
- Place a colour rectangle behind the photograph, shifted down-right or up-left so two adjoining edges remain visible.
- Start with a 6–12mm offset on A4; scale it to the image rather than treating the range as universal.
- Align the photo or backing block to the main text grid. Leave enough space around the exposed corner for the shape to read clearly.

**Starting points**
- Reuse one offset direction and distance within a related page family for a recognisable motif.
- Choose a palette colour with enough contrast against both paper and image edge.
- Omit additional drop shadows when the solid block already supplies the intended depth.
- Let text align with the photo, not wander around the backing shape, unless a deliberate wrap is part of the composition.

**Watch for:** An offset so small it looks like a registration error, inconsistent directions, or a backing block intruding into body copy.

**Construction:** Keep the rectangle and photograph as separate layers with explicit dimensions. Check that the backing remains visible after cropping, bleed and trim.
