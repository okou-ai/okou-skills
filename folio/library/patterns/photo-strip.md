# Photo strip

> **Modified by Okou.** Adapted from Folio; [source and authorship](../INDEX.md#source-and-authorship).

**Use for:** Showing applications, variants or a short visual sequence without disrupting the main page hierarchy.

**Composition**
- Place four to six equal-size thumbnails in one horizontal row, usually near the page foot.
- Anchor them to a solid band; on A4, a band around 30–45mm high is a useful starting point.
- Allow thumbnails to rise a few millimetres above the band if the overlap remains clear and intentional.

**Starting points**
- Use one aspect ratio, equal gaps and a common baseline aligned to the page columns.
- Select crops that remain recognisable at thumbnail size. Use fewer images if labels or detail need more space.
- Add concise labels when differences between variants matter; do not rely on tiny visual differences alone.
- Keep all essential content inside safe margins even if the band extends into bleed.

**Watch for:** Mixed thumbnail shapes, overly dense rows, unclear image order, or a band that becomes more prominent than the main story.

**Construction:** Use equal-width grid columns or a controlled row. Inspect crops, label contrast and effective image resolution at final size.
