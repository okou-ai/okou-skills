# Two-tone headline

> **Modified by Okou.** Adapted from Folio; [source and authorship](../INDEX.md#source-and-authorship).

**Use for:** A feature opener with a natural semantic split between a setup and a key phrase.

**Composition**
- Set a smaller, quieter first line above a much larger, heavier second line.
- Use colour or weight contrast to reinforce the split, not to highlight an arbitrary word.
- Share an optical left edge; large curved or diagonal letters may need a small alignment adjustment.

**Starting points**
- On A4, try an 18–30pt setup and a 60–100pt key phrase, with a size ratio around 2.5:1 or more when space permits.
- Limit the lockup to a neutral and one accent; verify contrast on the actual ground.
- Keep a consistent system across related feature openers, but use quieter headings for ordinary sections.
- Test the longest approved phrase before setting the scale. Avoid forced line breaks that change meaning or split a short phrase awkwardly.
- Adjust tracking only where the script supports it; Latin display habits do not transfer automatically to other writing systems.

**Watch for:** Every headline receiving the same accent-word treatment, a large but meaningless word, or compressed type used to rescue an unsuitable line length.

**Construction:** Keep the two lines inside one semantic heading, styled as separate spans. Check wrapping, optical alignment and reading order in the final output.
