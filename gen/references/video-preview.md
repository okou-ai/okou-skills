# Video Preview Approval

Apply this gate before submitting any generated-video job, including built-in, template, and connector routes.

1. Prepare a few keyframes that match the requested subject, style, and aspect ratio. Reuse suitable supplied or already approved images.
2. Show the actual keyframes through user-accessible links, summarize the intended motion briefly, and ask for confirmation. End the turn; do not submit the video job before confirmation.
3. Revise the preview when requested. Reuse an existing confirmation when the preview and motion plan are unchanged.
4. After confirmation, use the approved images as first/last frames or references when the chosen command supports them. Otherwise preserve the approved visual direction in the prompt.

Keep the approval message to the images, a short motion description, and one confirmation question. Do not add a second preview gate when a higher-priority template already completed the same approval with the same frames and motion plan.
