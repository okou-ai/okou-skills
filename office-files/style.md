# Document style

This baseline serves new Word/PDF documents across languages and topics. The blank assets contain typography and page settings only; choose any additional design for the task. User requirements and supplied templates take priority.

## Baseline

Measurements are in points unless stated otherwise. `12/16` means 12 pt type with a target text line spacing of 16 pt. Increase spacing for scripts/equations that need it; let image paragraphs and table rows grow naturally.

| Element | Style |
| --- | --- |
| Paper and text area | US Letter, single column; 5.5-inch text width; margins: left/right 108, top 65, bottom 64 |
| Body | 12/16; aligned to the reading start; 8 after paragraphs; no first-line indent |
| Document title | 18/22, bold; 14 after |
| Section heading | 13/17, bold; 16 before, 9 after; use real heading levels |
| Tables | 11/14; bold header row; table title above, at the same size |
| Chart labels | 10–11 at the final placed size, including after image scaling |
| Captions and sources | 10/13, below the figure |
| Footer, when used | 9/12; clear of the body |

Preserve these type sizes. Let content determine page count: wrap text, adjust columns, split tables, add pages, or use landscape pages as needed.

## Fonts and languages

- Word defaults: `ascii`/`hAnsi` = Times New Roman; `eastAsia` = Noto Serif CJK SC; `cs` = Noto Naskh Arabic. PDF defaults: Liberation Serif with Noto Serif CJK SC fallback. Adapt regional/script fonts and weights to the language.
- Keep Word's font slots separate in defaults, styles, and runs, including tables and headers/footers. Remove conflicting theme-font attributes; do not map Latin text to an embedded CJK font just to cover all scripts. Use a compatibility copy when repairing an existing file.
- For unavailable fonts, disclose a substitute with full script coverage and similar styling. Respect licenses, embed PDF fonts, and verify actual rendered fonts. Adapt shaping, line breaks, and reading direction; check RTL punctuation, numbers, and tables.

## Tables and charts

- Align labels to the reading start and numbers to the right; keep units, precision, and formats consistent. Repeat bold headers on continuation pages, keep ordinary rows together, and keep table titles with the header and first row. Choose rules, backgrounds, and padding for the content.
- Preserve chart aspect ratios and final label sizes. Use document fonts, leave room for legends, and distinguish series beyond color. Bar-chart value axes start at zero. State units and sources, label illustrative data, and use the same values as prose/tables. Keep figures with captions and sources where possible.

## Pagination and variants

Keep headings with following content and avoid isolated paragraph lines. Draw headers/footers once. Languages and formats may paginate differently. For A4 or two columns, adapt margins and column widths; wide tables/charts may span both columns. Check reading order and actual pagination.
