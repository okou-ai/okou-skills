# Retired PPT Avatar Video Template

Okou no longer provides this video template or built-in video, voice, or avatar
file generation. Do not run its former generation commands, JoggAI catalog
requests, or bundled rendering workflow. This notice remains available so an
existing agent that references the skill can load without invoking a retired
pipeline. The skill is no longer included in new default composes.

If the user explicitly requests a new video or narration, use the `gen` skill
and inspect `okou generate video --help`, `okou generate avatar-video --help`,
or `okou generate voice --help` as appropriate. These commands offer connector
discovery and guidance. Use only an available, authorized connector and follow
its skill; explain when none can fulfill the request. Do not promise a built-in
fallback or reuse the retired template.

Existing files remain accessible through ordinary artifact tools. Presentation
page screenshots and chat voice input/read-aloud are separate capabilities.
