# What may a new document change?

Ask this of the rendered pages before anything else. The answer is the route.
Ask it of the *next* document this template produces, not of the one in front
of you.

| A new instance changes | Route |
| --- | --- |
| only what goes in the blanks | **Slots** — publish the source |
| the content of each block, keeping the blocks and the way they are worded | **Composition** — publish the source |
| its own subject, at its own length | **Style sheet** — build `reference.docx` |

The first two publish the file because a style sheet carries neither the
wording nor the arrangement. They differ in what the package says may change,
which is the whole of what it says.

## Slots — everything outside the gaps is settled

A contract, an application, a certificate, an invoice. The page leaves
typographic gaps — a rule under spaces, a run of underscores, a parenthesised
instruction — and everything around them is fixed: the clauses, the notices,
the labels, the headings. Filling a gap is the only edit there is.

The package lists the gaps and what each holds, and says every other word is
reproduced as it stands.

## Composition — the arrangement and the voice carry over

A résumé, a set of minutes, an invitation, a one-page brief. A new instance
writes new content, but into the same blocks in the same order, phrased the
same way. Lists inside it run to a different length each time.

The package lists the blocks and what each holds, says to repeat or drop a
whole block of the same kind rather than build one, and keeps whatever fixed
wording the source carries between them.

## Style sheet — only the look carries over

A report, a whitepaper, a manual, a policy. The next one is on another subject
at another length, and nothing but paper size, margins, type, colour and the
heading hierarchy transfers.

## Telling them apart

- **Slots or Composition:** is there text outside the gaps that a new instance
  rewrites? None — Slots. Some — Composition.
- **Composition or Style sheet:** does the next one keep these same blocks, or
  pick its own? A résumé's sections are the document; a report's Summary and
  Findings are headings a style sheet already carries, over prose written at
  whatever length it needs.
- **A page carried by artwork** is never a style sheet. No description
  reproduces the image, and the text is set where the image leaves room.
- **Sparse pages are not slides.** A page can hold less text than a slide and
  still be a document; the dispatcher's rule about paper sizes applies here too.

Judge by what a new instance changes, never by what the document is called. A
one-page invoice and a ten-page contract are both Slots; a résumé and a set of
minutes are both Composition.
