# Retired Video Template

Okou no longer offers the `hand-drawn-fantasy-anime` video template or built-in video, voice,
avatar, or native video generation. This entry remains only so saved skill
references can still load. Do not run or reuse the former template, bundled
workflow, commands, or supporting instructions.

For an explicit new video, avatar, or narration request, use the `gen` skill
to discover an available, authorized connector and follow that connector's
skill. If none can fulfill the request, explain that limitation. Do not fall
back to a retired Okou template or managed pipeline.

Supporting resources remain historical source material, not an active
workflow. Existing files and independent screen-recording and camera tools
are unaffected.
